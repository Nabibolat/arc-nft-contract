# Arc NFT Smart Contract

Смарт-контракт NFT (стандарт ERC-721) для сети **ARC Mainnet**.

## Информация о контракте
* **Адрес:** `0x38470752ed8B3b9f02061bA2c15dA99abd7878ce`
* **Сеть:** ARC Mainnet (Chain ID 1243)
* **Стандарт:** ERC-721 (OpenZeppelin v5.0.0)
* **Статус верификации:** Успешно верифицирован на ArcScan

## Описание файлов
* `ArcNFT.sol` — оригинальный исходный код контракта.
* `ArcNFT_flattened.sol` — объединенный (flattened) код со всеми зависимостями OpenZeppelin, использованный для верификации.
